# ResumeAI

Paste your resume and a job description. Click one button. Get a tailored ATS-optimised resume and a cover letter, generated by Google Gemini.

## Requirements

A free Gemini API key from [aistudio.google.com](https://aistudio.google.com). No credit card required. Free tier allows 1,500 requests per day.

## Usage

1. Paste your resume text (or upload a PDF) in the sidebar.
2. Paste the job description in the main area.
3. Click "Tailor My Application". Enter your API key when prompted.
4. Copy or download the outputs.

Your API key is stored in sessionStorage only — it is never logged, never saved to disk, and clears when you close the tab. It is sent only to Google's Gemini API endpoint.

## Deployment

Push `index.html`, `style.css`, and `app.js` to a GitHub repository. In the repository settings, enable GitHub Pages on the `main` branch. The app is live at `https://yourusername.github.io/reponame`. No build step, no server, no configuration.
