# ResumeAI

Paste your resume and a job description. Click one button. Get a tailored ATS-optimised resume and a cover letter, generated by the [Groq API](https://groq.com) running the `llama-3.3-70b-versatile` model.

Fully client-side: there is no server, no build step, and no tracking. Everything runs in your browser.

## Features

- **PDF upload** — drop in a PDF resume and the text is extracted in-browser (via pdf.js).
- **Streaming output** — results stream token-by-token as they are generated.
- **ATS resume tailoring** — rewrites your resume to align with the target job description.
- **Cover letter generation** — produces a matching, role-specific cover letter.
- **ATS keyword match score** — shows how well the tailored resume covers the job description's keywords.
- **Local resume save** — keep your resume in the browser (`localStorage`) so it is there next time.
- **Copy, .txt and PDF export** — for both outputs.

## Requirements

A free Groq API key from [console.groq.com](https://console.groq.com). No credit card required. Groq's free tier is generous and fast.

The key starts with the prefix `gsk_…`.

## Usage

1. Paste your resume text (or upload a PDF) in the sidebar.
2. Paste your Groq API key (`gsk_…`) in the sidebar.
3. Paste the job description in the main area.
4. Click "Tailor My Application".
5. Copy or download the outputs (`.txt` or PDF).

Your API key is stored in `sessionStorage` only — it is never logged, never saved to disk, and clears the moment you close the tab. It is sent only to Groq's API endpoint.

## Deployment

Push `index.html`, `style.css`, and `app.js` to a GitHub repository. In the repository settings, enable GitHub Pages (Settings → Pages → Source: GitHub Actions). The app is live at `https://yourusername.github.io/reponame`. No build step, no server, no configuration.

A ready-to-use workflow is included at `.github/workflows/deploy.yml`, which publishes the repository root to GitHub Pages on every push to `main`.
